## found object · TRAILMARK

*TRAILMARK* is a solo cartography game about surveying an unexplored region. Its strongest design decision is negative: the book refuses to illustrate the world for you. The only picture that matters is the one the player draws.

Blankness becomes a component.

## studio fuel · one secret rule

A useful game-jam constraint: one session, one arbitrary law.

Examples:

- every sentence contains a physical object
- draw without curves
- build an RPG location containing no rooms
- make a collage only from images originally intended to sell something

The rule governs *how* you make, not *what* you make.

## found sound · an aquifer plugged into a car stereo

Brazilian artist Anti Ribeiro's *ALMA* grew from a residency above the Guarani Aquifer, using iron structures and an automotive sound system.

The useful chain is:

place → material system → sound

A place can become music by translating one of its systems instead of merely recording ambience.

## crosswire · solo RPGs × commonplace books

Solo RPGs suggest a better capture model: marks can carry state without requiring prose. A Field Notes book can do the same.

Capture first. Explain only when needed.

## 20 minutes · make an impossible map

Draw six symbols: mountain, water, settlement, ruin, forest, something wrong.

Then impose one rule:

> every new feature must explain something already on the map.

Do not write lore. Keep asking why the hell each thing is there.
