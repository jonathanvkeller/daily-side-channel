## found object · the synthesizer is playing itself

A feedback-based modular composition changes the musician's role from creating every event to designing a system that can create events.

Feedback can mean:

> build a system with memory.

## found object · the eight-page anti-phone

An eight-page printable zine uses the physical page number as a d8: flip blindly and use the page you land on.

The publication becomes:

content + interface + randomizer

The larger notebook idea is delicious: let the object's physical properties perform mechanics.

## studio fuel · publish the scene

A small press can become memory infrastructure for a creative scene.

Shows vanish. Flyers get trashed. Websites die. People move. Publishing can be the receipt.

## rabbit hole · the tromba marina

The tromba marina is an enormous bowed monochord whose bridge is deliberately unstable, producing a rattling buzz.

Centuries before distortion pedals, instrument makers deliberately engineered mechanical instability to make better noise.

## crosswire · medieval buzz × noise-rock bass

Instead of asking "what effect should I add?" ask:

> what can I make physically unstable?

Loose hardware, microphonics, fret clatter, cabinet vibration, sympathetic strings.

## 20 minutes · turn your Field Notes into a machine

Assign functions to four physical properties of the notebook: left/right page, page number, vertical position, distance from the cover.

Then make one thing using only those rules.
